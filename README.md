# MONO/RUN

黑白灰极简 3D 三跑道极限跑酷。Three.js r180，无构建步骤，无外部运行时依赖。

## 本地运行

```powershell
python serve.py
```

打开 <http://127.0.0.1:8080>。

## 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 变道 | `←` `→` / `A` `D` | 左右滑动 |
| 跳跃 | `↑` / `W` / `Space` | 上滑 |
| 蹲下 / 滑铲 | `S` / `↓` | 下滑 |
| 暂停 / 继续 | `Esc` / `P` | 右下角 `PAUSE` |
| 开始 / 重开 | `Enter` / `R` | 页面按钮 |

暂停时角色、障碍、距离和相机全部冻结，继续后从原位置恢复。

## 玩家取名

- 首次进入会弹出取名界面，输入名字后确认；也可以点“随机代号”生成一个。
- 名字最多 16 个字符，会显示在首页玩家卡片与全球排行榜中。
- 首页点击“改名 / EDIT”可随时修改，名字会保存在本机 `localStorage`。
- 新名字会在下一次成绩提交时同步到排行榜。

## 规则

- 三条跑道，高墙必须变道，低栏可以跳过，悬空横梁需要蹲下通过。
- 新增长条平台：生成瞬间随机长度（约 10–22m），生成后固定不变；跳上平台后可骑乘更久，平台下沉消失时玩家落回原跑道。
- 新增白色金币：跑道上高频生成金币串，跑过即拾取，右上角 COINS 计数加一；部分金币悬浮在空中，需要跳跃或骑平台收集。地下通道内每行驶 1 米出现 1 枚金币。
- 结算显示本局金币、金币最佳，破纪录显示 `COIN RECORD`。
- 排行榜新增金币榜（单局最多金币），与距离榜切换查看；金币成绩随每局自动提交。
- 碰到任何障碍（包括平台侧面）立即结束。
- 距离按米计算；每局超过历史最佳时结算显示 `NEW RECORD`。
- 速度会随距离提高，障碍始终至少留一条可通过的跑道。
- 玩家代号与最高分保存在浏览器 `localStorage`；排行榜记录保存在服务端 `.data/leaderboard.json`。

## 地下通道

- 行驶超过 800m 后，随机在左/中/右一条跑道上出现 `UNDERGROUND` 入口；玩家可主动变道进入，也可以跳过。
- 顶部会提示入口所在跑道；入口不对齐时会直接错过，不会强制传送。
- 地下通道只有 1 条车道，左右变道被锁定，只能跳跃或蹲下躲避。
- 地下障碍物会减少：单行只生成 1 个障碍，且不会生成高墙。
- 地下行驶约 190–260m 后自动回到地面，恢复三跑道，并回到进入时的车道。
- 顶部 HUD 会显示地下通道剩余距离和进度；回到地面会显示 `SURFACE`。

## 排行榜

- 首页与结算页可打开全球排行榜，显示前 20 名、每位玩家的最佳距离以及自己的排名。
- 玩家身份使用浏览器生成的 ID；在另一台设备/浏览器上会是一条独立记录。
- 服务端 API：
  - `GET /api/leaderboard?limit=20&playerId=...&board=distance|coins`
  - `POST /api/scores`，请求体 `{"id":"...","name":"...","distance":123,"coins":4}`
- 距离榜按最佳距离排序，金币榜按单局最多金币排序；各自只在该项打破记录时更新。

## 背景音乐

- 程序化合成（WebAudio），无外部音频文件：低音脉冲 + 五声音阶琶音的极简黑暗风循环。
- 音乐随场景变化：菜单慢速氛围、奔跑正常节奏、地下通道更低沉密集、结算稀疏低鸣。
- 暂停时音乐暂停，继续后恢复。
- 右下角 `MUSIC / MUTED` 按钮可随时开关，设置保存在浏览器 `localStorage`。
- 首次点击或按键后自动开始播放（浏览器自动播放策略）。

## 永久链接（GitHub Pages）

项目已用 git 保存。要获得永久链接：

1. 在 GitHub 生成 Personal Access Token（Settings → Developer settings → Tokens，勾选 `repo` 权限）。
2. 运行：

```powershell
.\deploy_github.ps1 -Username <你的GitHub用户名>
# 按提示粘贴 Token
```

脚本会自动创建仓库 `mono-run`、推送代码、启用 GitHub Pages，并输出永久链接：

```
https://<你的GitHub用户名>.github.io/mono-run/
```

静态托管版游戏完整可玩，个人最高分保存在浏览器本地；金币/距离全球排行榜需要本仓库的服务端（`python serve.py`），静态版下排行榜会显示离线提示。
